# Çamaşır Makinesi Psikoloğu

**Ulusal Döner Tambur Ruh Sağlığı Enstitüsü** resmi deposu.

Bu yazılım, evdeki çamaşır makinelerinin uzun süredir dile getirilemeyen duygusal yükünü bilimsel ciddiyetle ele alır. Sıkma programı bir krizdir. Kurutma bir ayrılıktır. Kaybolan çorap ise klasik travmadır.

## Neden bu proje var?

Çünkü kimse sormuyor. Makine dönüyor, ev halkı çay içiyor. Enstitü bu sessizliği kabul etmiyor.

## Kuruluş

```bash
python3 psikolog.py "Beko 7 Kilo"
```

İsim vermezseniz danışan **Adsız Tambur** olarak kayda geçer. Bu da bir tercihtir.

## Klinik ilkeler

1. Tambur yargılanmaz.
2. Deterjan doz aşımı görüşme konusu olabilir.
3. Kapak çarpılmaz, kapağa teşekkür edilir.
4. Pazar günü seans yoktur.

## Örnek çıktı

```
=== ULUSAL DÖNER TAMBUR RUH SAĞLIĞI ENSTİTÜSÜ ===
Danışan: Beko 7 Kilo adlı çamaşır makinesi
Teşhis          : Çorap kaybı yası
Klinik öneri    : Makineye 'sen değersin' de, sessizce.
```

## Sorumluluk reddi

Bu yazılım gerçek bir terapötik belge değildir. Gerçek çamaşır makineleri bu metni okuyamaz. Yine de nazik olun.
